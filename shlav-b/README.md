# שלב ב׳: מרכז ההכנה והמנוע לחבילות לימוד

- `app/` — קוד האפליקציה (עברית, RTL): לשוניות היום, נושאים, מבחנים קודמים וארגז כלים, ונגן שמריץ כל חבילה. בנייה: `python3 shlav-b/app/build.py out.html`.
- `data/shlav-b-data.json` — הבחינה, 141 הנושאים, מבחני עבר, תבנית תשובה, עקרונות מחוון, EBM, חוקים ונושאים חמים. בלי התקדמות אישית.
- `packs/` — חבילות לימוד מוכנות (`incont` מובנית באפליקציה; השאר נטענות מהמאגר של האפליקציה).
- `engine/pack-format.md` — פורמט החבילה. `engine/validate_pack.py` — בדיקת תקינות.
- `../.claude/skills/shlav-b-pack/` — המנוע: ב-Claude Code, `/shlav-b-pack <topic-id>` קורא את מקורות העוגן מתיקיית ״שלב א״ ב-Google Drive, כותב חבילה בעברית, בודק אותה ומעלה אותה לאפליקציה.

ההתקדמות נשמרת באפליקציה עצמה, לכל משתמש בנפרד, ומסונכרנת בין מכשירים.
