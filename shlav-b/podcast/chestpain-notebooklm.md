## מה לבדוק בהאזנה
- [ ] חשד גבוה: אמבולנס, בלי לעכב ל-ECG או טרופונין.
- [ ] Marburg ≥ 3; נאמר שאינו שולל ACS.
- [ ] Aspirin 162–325, חמצן < 90%, Nitroglycerin תת-לשוני 0.4.
- [ ] טרופונין 0 ו-3 שעות; HEART ‏0–3 / 4–6 / 7–10.
- [ ] PCI: ‏AFP 120 דקות, גורול 90.
- [ ] Prasugrel אסור אחרי שבץ/TIA; Ezetimibe רק מעל 70 על סטטין במינון המרבי הנסבל.
- [ ] כאב חריף בסיכון ביניים עם CAD ידוע < 50%: לשקול שחרור ומעקב או צנתור.
- [ ] פריקרדיטיס: 2 מ-4; גורם סיכון אחד ← אשפוז.
- [ ] כל התרשימים והטבלאות הוזכרו; אין מידע מחוץ למקורות.
- [ ] לשון זכר ונקבה נכונה.
